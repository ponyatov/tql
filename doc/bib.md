# [[TQL]] books & resources

1. "[[dot/Domain Modeling Made Functional]]" by [[people/Scott Wlaschin]]

	- While not exclusively about tree processing, this book covers recursive data structures (like trees) in the context of domain modeling using F#.
	    
	- It includes practical examples of tree traversal and manipulation in a functional style.
	    
	- Highly recommended for learning F# and functional data processing.
    
2. "Expert F#" by [[Don Syme]], Adam Granicz, and Antonio Cisternino

	- A comprehensive book on F# that includes advanced topics like recursive data structures and tree processing.
	    
	- Covers pattern matching on trees and functional algorithms.
